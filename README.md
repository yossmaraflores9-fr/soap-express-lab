# Práctica de Laboratorio: Servicios Web SOAP con Express y WSDL

## Descripción
Esta aplicación expone dos servicios web SOAP utilizando Node.js y Express. Cada servicio cuenta con su propio contrato WSDL y ofrece dos operaciones independientes.

## Requisitos
- Node.js (v18 o superior)
- npm
